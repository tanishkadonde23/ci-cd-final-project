# CI/CD Pipeline with GitHub Actions, Tekton, and OpenShift

## Project Overview

This project demonstrates the implementation of a Continuous Integration and Continuous Deployment (CI/CD) pipeline using GitHub Actions, Tekton, and OpenShift.

## Objectives

- Automate code quality checks using linting.
- Run unit tests automatically.
- Configure CI workflows using GitHub Actions.
- Define pipeline tasks using Tekton.
- Deploy and validate the application on OpenShift.

## Technologies Used

- GitHub
- GitHub Actions
- Tekton Pipelines
- OpenShift
- Python
- flake8
- nose
